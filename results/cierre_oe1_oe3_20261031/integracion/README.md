## Honest findings from running it

1. **`models/ckpt_audio_text.pt` identifies itself as a smoke-test checkpoint**: its notice reads "PRUEBA DE HUMO - etiquetas
   heurísticas, NO válida como evidencia" (the text is stored with broken accents inside the checkpoint). The service passes it
   through verbatim as warning `engine_provenance` and `provenance.checkpoint.checkpoint_notice`; every event is therefore
   pipeline output, not a finding. sha256 `87f95108...b669`. Which checkpoint is the intended official one is a decision for the owner.
2. The 36 s clip yields a `block` event; the service adds warning `class_block_not_measurable` (n=2 in the development corpus).
3. `score.kind = max_window_class_probability` is the raw maximum softmax of an uncalibrated model; the contract marks it
   `calibrated: false`, `label: uncalibrated`. The other task suggested renaming the kind in a future version (breaking in v1).
4. The service has no state "uncertain" and none was invented; zero events is reported with warning `no_events`
   ("this does not certify fluent speech").
5. A bug found only by the first real HTTP run (before the unit tests existed): FastAPI could not resolve `Request` when it was imported inside the factory function under `from __future__ import annotations` (HTTP 422 on every POST). Fixed with module-level imports; the `TestClient` tests now cover it.

## Tests

`tests/test_service_contract.py`, `test_service_analyzer.py`, `test_service_server.py`, `test_service_microphone_check.py`:
schema file equals the Python source; validator rejects calibrated/unknown/NaN/zero-for-absence; error classification;
defaults p0/V0 and unchanged engine call; experimental flags; text off by default; no absolute paths in output; nothing written
to disk; service imports nothing from the app or `scripts/` and the engine never imports the service; server lifecycle, 400/404/413,
loopback refusal, CORS opt-in and preflight. One slow test (`MRCD_SLOW=1`) compares service events with `DisfluencyEngine.analyze_file`
on the real clip (passed once). Mutation sanity check done by hand (flipping `calibrated` fails 2 tests). Literal suite logs in `logs/`.
