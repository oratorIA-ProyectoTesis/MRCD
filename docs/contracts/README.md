## Ground rules reflected everywhere

1. Scores are raw softmax/sigmoid outputs of an uncalibrated model, never probabilities; no calibration exists.
2. Absence is not zero: a measure that is not available is reported as unavailable with a reason.
3. Event intervals are decision strides, not human boundaries.
4. Only `filler_word`, `prolongation` and literal repetition have (partially) compatible human references; `block`, `rhetorical_pause`, `neutral_pause` have none and `revision` is an approximation. Nothing is validated.
5. Video is never an input to the available engine and never a source of psychological inference.
6. "Experimental" components (ASR profile p1, Vc head, `live_cfg_v3` as an option) are marked wherever they appear.

## Reproduce the fixtures and checks (repo root, Git Bash)

```bash
# 1) real engine outputs (needs the local Whisper cache; HF_HUB_OFFLINE=1 avoids a stall seen on this machine)
HF_HUB_OFFLINE=1 OMP_NUM_THREADS=4 .venv/Scripts/python.exe -u docs/contracts/examples/generate_examples.py \
  --source data/clips/FIwdDFht7FE.wav --start 60 --dur 20 --out docs/contracts/examples --clip <scratch>/clip.wav
# 2) service documents on the same excerpt (contract mrcd.analysis/v1)
HF_HUB_OFFLINE=1 OMP_NUM_THREADS=4 .venv/Scripts/python.exe -m mrcd.service analyze <scratch>/clip.wav --out docs/contracts/examples/service_analysis_v1.json
# 3) report-side mapping examples
.venv/Scripts/python.exe docs/contracts/build_report_section.py docs/contracts/examples/service_analysis_v1.json docs/contracts/examples/app_report_section_example.json
# 4) validate everything
.venv/Scripts/python.exe docs/contracts/validate_examples.py
```

The excerpt is seconds 60-80 of `data/clips/FIwdDFht7FE.wav` (git-ignored source audio, a public talk; sha256 of the excerpt in `examples/provenance.json`). The audio is not versioned; the fixtures contain the 276-character transcript of the excerpt. Wall times in `provenance.json` are single runs on a machine shared with other jobs and are **not benchmarks**.
