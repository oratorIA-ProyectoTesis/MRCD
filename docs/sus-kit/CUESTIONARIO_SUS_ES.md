## Cómo se puntúa

Ítems impares (1, 3, 5, 7, 9): respuesta menos 1. Ítems pares (2, 4, 6, 8, 10): 5 menos la respuesta. Se suman las diez contribuciones y se multiplica por 2,5; el resultado va de 0 a 100. No es un porcentaje. La interpretación y el umbral 70 (de `OBJETIVOS.MD`) se discuten con el asesor; el valor 68 se cita a veces como media de referencia internacional, pero esa cifra **no se verificó** aquí y no se usa como criterio.
